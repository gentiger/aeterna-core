# 新加坡保衛戰 1942 — 3D 戰史運鏡
### The Battle of Singapore · Interactive 3D War-History Special

以「電視特別節目」風格呈現的 **新加坡保衛戰（1942 年 2 月 8–15 日）** 互動式 3D 視覺化。
畫面像歷史節目／戰棋遊戲，可自由旋轉鏡頭，沿時間軸觀看雙方陣型、移動方向、
指揮官、重大事件與戰力消長，並帶有槍炮與天氣特效。各軍勢的家紋繪於軍旗之上。

## ▶ 執行方式

ES 模組需透過 HTTP 載入（不能直接用 `file://` 開啟）：

```bash
# 在專案目錄下
python3 -m http.server 8000
# 然後瀏覽器開啟 http://localhost:8000/
```

> Three.js (r160) 由 unpkg CDN 以 importmap 載入，首次執行需可連外網。
> 若需離線，可自行將 three 的 `build/` 與 `examples/jsm/` 放到本機並改寫 importmap。

## 🗺 內容設計

- **地形與地名**：新加坡島、柔佛海峽、長堤、薩里蒙海灘、登加機場、武吉知馬高地、
  巴西班讓、麥里芝水庫、市區、樟宜等，皆以程序化高程圖建構並標示中英地名。
- **軍勢（紅＝日軍 / 藍＝英軍）**：每支部隊以圓盤、光柱、家紋軍旗與浮動標籤呈現，
  標示部隊番號、大將姓名與戰力，並以箭頭顯示移動方向。
- **時間軸 7 幕**：登陸 → 強渡 → 機場失守 → 武吉知馬陷落 → 退守市區 →
  巴西班讓死戰 → 帕西瓦爾投降。每幕更新陣型、戰力長條與重大事件。
- **特效**：曳光彈對射、槍口火光、拋物線砲擊與爆炸、季風暴雨與閃電、海浪、
  由夜入晝的天空變化、電影式自動運鏡。
- **家紋／紋章**：近衛師團（菊紋）、第5師團（陸軍星）、第18師團（櫻花）、
  司令部（五七桐）；英軍（米字旗）、澳軍（七角聯邦星）、印度軍（法輪）、
  英第18師（皇冠）、馬來軍團（新月星）。

> 部分家紋／紋章為配合「節目／遊戲」風格之示意設計，非嚴格史料考證。
